# Профиль компании-экспортёра

Скилл для Codex и Claude Code. Агент собирает данные о вашей компании в одну папку, проверяет их с вами в интервью и дальше поддерживает в актуальном состоянии.

Профиль нужен агенту для любой экспортной задачи: найти компании в новой стране, расставить приоритеты, написать письмо, подготовиться к встрече. Без профиля агент не понимает, кому и что вы продаёте, и любой результат получается общим.

## Установка

Проще всего попросить агента. Напишите в Codex или Claude Code:

```text
Установи скилл из https://github.com/Vladick-Pick/export-company-profile-skill
```

Или вручную, в терминале:

```bash
git clone https://github.com/Vladick-Pick/export-company-profile-skill.git
```

```bash
mkdir -p ~/.codex/skills && cp -r export-company-profile-skill/company-profile ~/.codex/skills/
```

```bash
mkdir -p ~/.claude/skills && cp -r export-company-profile-skill/company-profile ~/.claude/skills/
```

Вторая команда ставит скилл для Codex, третья — для Claude Code. После установки перезапустите агента.

## Как собрать профиль

1. Создайте папку, например «Экспорт ИИ», и откройте её в агенте.
2. Напишите: «Собери профиль компании».
3. Агент спросит название компании, сайт или ИНН и какие у вас есть материалы. Положите в папку то, что есть: презентацию, прайс, каталог, сертификаты, записи встреч. Остальное агент найдёт в открытых источниках.
4. Пройдите интервью. Агент показывает, что нашёл и где, и задаёт по одному вопросу со своим вариантом ответа. Отвечайте «да», поправкой или «не знаю». Интервью можно прервать и продолжить позже.
5. Утвердите версию 1.0.

Сборка с поиском занимает 20–30 минут, интервью — ещё 20–40.

## Как профиль живёт дальше

| Когда | Что написать агенту |
|---|---|
| После встречи | «Обнови профиль по этому транскрипту» |
| Новый прайс, продукт, сертификат | «Обнови профиль по этому файлу» |
| После рассылки | «Обнови гипотезы по ответам» |
| Раз в месяц | «Почисти профиль» |

Каждое изменение агент тоже согласует с вами по одному вопросу.

## Что будет в папке

```text
AGENTS.md          правила для агента в этой папке
профиль/
  профиль.md       сводка о компании на две страницы
  словари.md       продукты, сегменты, позиции у клиента, УТП
  вопросы.md       открытые вопросы
  изменения.md     журнал версий
источники/         копии сайтов и документов, реестр источников
входящие.md        новые факты, которые агент нашёл в работе
```

В профиле девять блоков: компания, продукты, экспортный опыт, целевые страны, сегменты, позиции у клиента, УТП, экспортные объекты (продукт × страна × канал), ограничения.

## Правила, которые держит агент

- **У каждого утверждения есть статус, источник и дата.** Статусов четыре:
  - «Независимый источник» — реестр, СМИ, выставка, дистрибьютор;
  - «Данные компании» — ваш сайт, прайс, ваши ответы;
  - «Требует подтверждения» — источники расходятся;
  - «Рабочая гипотеза» — вывод агента.
- **Гипотезу в факт превращаете только вы.**
- **Агент не придумывает.** Не нашёл — так и пишет и заводит вопрос.
- **Старое не удаляется.** Заменённое помечается, история хранится в git.
- **Посреди рабочей задачи агент профиль не меняет.** Новые факты он складывает во «входящие», и вы решаете, что из них взять.

## Конфиденциальность

Профиль содержит данные вашей компании. Храните папку у себя и не выкладывайте её в публичный репозиторий.
